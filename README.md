# APoker Android App

<p align="center">
  <img src=".github/logo.png" alt="apoker-android-app logo" width="128" />
</p>

An early Android poker app that deals random playing cards.

## What it does

It holds images for a full deck of cards and picks cards at random to
show on screen. It is an early prototype rather than a complete game.

## Tech

- Java for Android

## Building

This is an Eclipse Android project (`AndroidManifest.xml`,
`default.properties` and `proguard.cfg`). Import it into Eclipse with
the Android Developer Tools, or build it with the Android SDK.
